## 技术架构

### 1、桌面应用架构

本项目采用 **Electron 单体架构**，打包成单个可执行文件：

```
桌宠应用（单个可执行文件）
├── 主进程（Main Process）- Node.js 环境
│   ├── 系统集成（窗口、托盘、自启、通知）
│   ├── 硬件控制（键盘鼠标、屏幕捕获、音频）
│   ├── 数据存储（SQLite、文件、配置）
│   └── 网络服务（AI API、数据同步）
├── 渲染进程（Renderer Process）- Chromium 环境
│   ├── UI 界面（React）
│   ├── 动画系统
│   └── 交互逻辑
└── 资源文件（模型、服装、音效、配置）
```

### 2、技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Electron + React + TypeScript |
| 构建 | Vite + electron-builder |
| 数据库 | SQLite（本地） |
| AI 服务 | OpenAI API |
| 渲染 | Canvas / Three.js |
| 动画 | Lottie / Spine |

### 3、核心功能
- **换装系统**：类似闪耀暖暖，用户可以为桌宠更换不同的服装、配饰和发型。
- **游戏功能**：桌宠可以与用户一起玩小游戏，如猜拳、拼图等。
- **互动功能**：桌宠可以根据用户的行为和屏幕内容产生互动，如当用户在工作时提醒休息，当用户在看电影时提供相关评论。
- **AI聊天**：桌宠可以通过语音和文字与用户聊天，提供陪伴和娱乐。

### 4、用户使用流程
1. **安装与初始化**：用户下载并安装桌宠应用，首次启动时进行基本配置。
2. **配置设置**：用户根据个人喜好配置桌宠的各项参数。
3. **日常互动**：用户与桌宠进行日常互动，如聊天、游戏、换装等。
4. **数据管理**：用户可以选择是否将数据同步到服务器，以及管理本地数据。

### 5、系统要求
- **硬件要求**：
  - CPU：至少2核处理器
  - 内存：至少4GB RAM
  - 存储空间：至少500MB可用空间
  - 网络：可选，用于AI服务
- **软件要求**：
  - Windows 10或更高版本
  - macOS 10.14或更高版本
  - 主流Linux发行版
